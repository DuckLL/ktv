# 桌機與手機播放頁

主內容依 **MV → 歌詞 → 音高圖** 排列。桌機依功能區擺放設定；手機將即時操作留在外層，其餘設定移入抽屜分頁。MV 預設顯示，原唱音高圖預設顯示，麥克風由使用者明確開啟。

[討論階段的互動示意](previews/mobile-player.html) 僅使用示意資料；實際播放器以 `src/ktv/static/player.html` 為準。

## 桌機

| 區域 | 控制 |
| --- | --- |
| MV | 影片原生播放／暫停、進度、音量／靜音與全螢幕控制 |
| MV 右側 | 直接顯示音量、導唱及 key；伴唱、混音滑桿、原唱維持同一行，另有 MV 開關 |
| 頂列 | 原影片 YouTube 來源 |
| 歌詞上方 | −0.5 秒、−0.2 秒、目前時間差、+0.2 秒、+0.5 秒、重置，全部直接可用 |
| 歌詞 | 完整列表，可捲動與點句跳轉，當前句粉色高亮；上／下一句各佔左右一條長按鈕 |
| 音高圖旁 | 顯示開關、低八度、容錯、收音按鈕；進階收音和延遲補償按需展開 |
| 聲音區下方 | 歌詞版本、搜尋、候選清單，以及清除歌詞記憶 |

常用設定不放入桌機分頁。播放與進度使用影片原生介面，讓主畫面留下更多歌詞空間。時間差及音準設定留在各自功能區。

原生影片音量與靜音控制伴唱、原唱兩軌，與右側設定音量及鍵盤同步；改變混音或 key 時保留整體音量和靜音狀態。

寬螢幕的 MV 高度上限為視窗高度的 44%；例如 1366×900 下為 396 px。收起 MV 時保留 96 px 的原生播放器，可繼續播放與拖曳進度，聲音調整仍在右側。

## 手機

頂列顯示返回、歌名、YouTube 與「調整」。播放、暫停及進度使用影片原生控制，不另設播放列。影片下方常駐一行「伴唱／原唱混音滑桿／原唱」，方便邊播放邊調整導唱比例；接著是歌詞時間差、完整歌詞與音高圖。歌詞上方常駐 ±0.2 秒、±0.5 秒、時間差與重置，左右各有一條長形上一句／下一句按鈕，歌詞本身可捲動。

升降 key 固定放在播放分頁，主畫面騰出的高度分配給音高圖。圖表依剩餘空間最多加高 53 px，並保留至少 180 px 的歌詞區；較矮螢幕維持緊湊圖表。以 390×844 為例，繪圖區從約 59 px 加高至約 112 px。視窗高度、影片比例、MV 開關及音高圖顯示變動時重新分配，桌機維持原來的高度。

手機依影片原始比例顯示，例如 4:3 MV 使用整個手機寬度；較高的直式影片限制高度，保留歌詞和播放操作。影片內容等比顯示，不裁切。影片只顯示原生控制；YouTube 放在頂列，MV 開關放在「調整 → 播放」。桌機與手機皆保留影片內建全螢幕，額外的全螢幕按鈕已移除。收起 MV 後保留一條精簡的原生播放器，仍可暫停及拖曳進度。

「調整」抽屜一次顯示一組設定：

- **播放**：音量、升降 key 與 MV 開關。
- **歌詞**：版本、搜尋與清除記憶。
- **音準**：圖表顯示開關、低八度、容錯及進階收音設定。

原生介面未提供音量滑桿的手機，可使用系統音量或播放分頁的音量設定；原生靜音仍會連動兩軌，解除靜音保留原先的音量與混音比例。

抽屜支援鍵盤分頁、Escape、點背景關閉和焦點還原。開啟設定不中斷播放；手機橫向使用左側 MV、右側混音、時間差、歌詞與音高圖。橫向收起 MV 後，混音列位於左側的精簡播放器下方，右側保留完整歌詞空間。

## 歌詞顯示與記憶

兩種版面都保留所有歌詞，文字不以只顯示三句的方式隱藏。播放切換句子時自動置中；手動滑動或滾輪操作後暫停置中五秒，讓使用者閱讀其他段落。

歌詞時間差完全手動調整，自動校正與開關已移除，舊的開啟偏好也不會觸發校正。既有版本與時間差照常還原，可按重置回到零。

「清除記憶」會清除目前歌曲的已選歌詞與各版本時間差。已明確清除的歌曲在重新開啟時維持未選擇，讓使用者手動搜尋，避免自動選回錯誤版本。選擇新版本後恢復一般記憶流程，也可明確按「重新自動找歌詞」重試。

清除操作會取消尚未送出的時間差儲存，等待先前已送出的版本及時間差保存完成，再執行刪除。刪除失敗保留目前歌詞並顯示重試訊息。

## 驗證

- 1366／1280／800／768／430／390／320 px 排版，390×700 較矮手機與 844×390、568×320 橫向操作。
- 桌機常用控制直接顯示，聲音在影片右側，伴唱、混音滑桿、原唱維持同一行。
- 桌機與手機皆用原生播放控制，外層 ±0.2 秒、±0.5 秒、重置維持同列，上／下一句位於歌詞兩側。
- 手機 4:3 MV 使用原始比例滿寬顯示，影片上只有原生控制；直式影片限制高度並保留歌詞區。
- 手機 YouTube 位於頂列、MV 開關位於播放分頁，上／下一句長按鈕位於歌詞兩側。
- 手機混音在主畫面維持單行，可直接切換伴唱、原唱與中間比例；升降 key 固定在播放分頁，原高度分配給音高圖。
- 完整歌詞可捲動，當前句高亮且只捲動歌詞容器。
- 播放、跳轉、收音、全螢幕、設定保存與螢幕切換正常。
- 清除錯誤版本、沒有同步歌詞的版本、重新載入、延遲儲存及失敗重試。
